IRONICS — BOLT · REVISED (cyan core / purple rim)

House-Cyan #00F8FF core + Arc-Violet #A855F7 rim = the electric-arc accent. For sign-off.

Chosen secondary: ARC VIOLET · #A855F7

WHY this value blends (not clashes): it is a blue-leaning violet (hue ~271°), so the cyan(182°)→violet(271°) transition sweeps through electric blue (~220°) — the rim reads as one continuous arc off the cyan, a single electric palette rather than two colors fighting. Its high saturation matches cyan's neon energy. Deliberately bluer than the existing identity-axis NeonPurple #CB00FF (that one is magenta-leaning, for team/store, not brand chrome). Role: RIM / EDGE-GLOW only — never the readable core, fill, or text.

4 · the blend rule (proposed for the SSOT)

Cyan core + purple rim = the electric-arc accent. Cyan LEADS (core / fill / readable text / active state). Arc-Violet SUPPORTS (rim / edge-glow / halo / focus / hover). Purple NEVER touches the readable core. Rim is size-gated: ON at ≥64px (lockup, hub emblem, large tiles); the mark goes cyan-dominant at ≤32px (HUD watermark, 16px favicon) so it stays crisp. On the in-match combat HUD the readability law still rules — purple stays edge-glow chrome on menu/header surfaces, never a solid combat-overlay marker (clears the INDIGO beam hue).
