Proof standard. ✅ means watched in PIE on a controllable pawn — two clients wherever replication is claimed, a dedicated server wherever join or travel is claimed. Never "compiles". Each phase ends with a commit, push to personal/main, triple-hash verification, clean tree.
Two things never regress. The match loop and the matchmaking pipeline. No match experience, FlexMatch rule set, queue, SSM routing value, or League/Staked door code path is edited anywhere in this programme. Every gate from H1 onward re-runs the 2-client match fire proof.
Operator intent is fixed. Zones, flows, map choice, and the "weapon-spawner-as-display" model come from Lobby_Upgrade_Doc.docx and are not reopened. Where the helper doc's mechanism would break a proven system, the SSOT §2 records a conformance ruling — same behaviour, delivered through the existing seam.
