IRONICS — 4-COLOR ROLE PALETTE · STYLING SAMPLE

Each color has ONE job. "When appropriate" = use the color whose job fits the element — not all four everywhere.

THE ROLES (the rule)

ELECTRIC BLUE — #1E5AFF · PRIMARYGlass fill / tint · active & selected state · the house lead color (replaces Lyra cyan).
ARC VIOLET — #A855F7 · ACCENTNeon-pipe edge-glow · focus / hover · rim framing. Never the readable core.
BLACK · DEPTH / CONTRASTPanel-depth backing · contrast behind text for legibility · the dark base the neon reads against.
WHITE · TEXT / HIGHLIGHTSPrimary readable labels · key specular highlights on glass edges · max-contrast text.

LOGIC: blue LEADS (fill/active) · violet ACCENTS (edge/focus) · black gives DEPTH/contrast · white carries TEXT/highlights. One primary job each.
